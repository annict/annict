## 2026年10月25日の改定について

本ポリシーを2026年10月25日に改定し、同日から施行しました。
ユーザーの皆さまに必要な対応はありません。
改定後の取扱いに同意いただけない場合は、本サービスの利用をやめ、[アカウントの削除ページ](/settings/account/deletion/new)から退会できます。

今回の改定で明確にした点・変えた点は次のとおりです。

- 取り扱う情報と利用目的を、実際の取扱いに合わせて1つの表にまとめました
- アニメ作品の制作に関わる方 (人物) の情報の取扱いと、掲載停止の申出の窓口を定めました
- Web APIで提供している情報を説明し、オプトアウト方式による第三者提供の定めを削除しました
- 利用目的から、第三者へのデータの提供とマーケティングへの利用を削除しました
- 利用している外部のサービスと、広告などのために外部へ送信される情報を明記しました
- 安全管理措置とログの取扱いを定めました
- 開示等の請求の方法・本人確認・手数料を定めました
- 退会したときに削除する情報と、一定期間残る情報を実態に合わせて書き直しました
- 住所はお問い合わせに応じて回答することを定めました
- 本ポリシーを変更するときの通知の方法を改めました

改定前の版は[2019年2月16日施行版](/privacy/archive/20190216)で読めます。

アニメ視聴記録サービス「Annict」(以下「本サービス」) の運営者 (以下「運営者」) は、本サービスで取り扱う個人情報について、次のとおりプライバシーポリシー (以下「本ポリシー」) を定めます。

## 1. 取り扱う情報

運営者は、本サービスのユーザーについて次の情報を取り扱います。

- アカウントの情報: メールアドレス、ユーザー名、パスワード (ハッシュ化した値だけを保存します)
- プロフィール: 名前、自己紹介、URL、プロフィール画像、背景画像
- 投稿と活動: 記録、感想、視聴ステータス、ライブラリ、いいね、コメント、フォロー、お気に入り、コレクション、フォーラムの投稿、Annict DBでの編集
- 設定: 表示言語、タイムゾーン、通知の設定など
- サポーターの情報: Stripeの顧客ID、サブスクリプションの状態
  - 以前にGumroadで申し込んだサポーターは、Gumroadの購読者ID・メールアドレス・購読の状態
  - カード番号などの支払いの情報は、ユーザーが決済事業者 (Stripe) の画面に直接入力し、運営者は取得しません
- お問い合わせの情報: お問い合わせのメールアドレスと内容
- アクセスの情報: IPアドレス、閲覧したページのURL、アクセスした日時、ブラウザの情報 (User-Agentなど)、Cookie

本サービスは、ログイン状態を保つためと、機能を段階的に公開するときに端末を見分けるためにCookieを使います。

このほか、アニメ作品の制作に関わる方の情報を取り扱います (「3. 人物情報の取扱い」)。

## 2. 利用目的

運営者は、取り扱う情報を次の目的で利用します。

| 利用目的 | 利用する情報 |
| --- | --- |
| 本サービスの提供 (アカウントの登録と認証、投稿の保存と表示、通知) | アカウントの情報、プロフィール、投稿と活動、設定 |
| サポーターの申込みの受付、特典の提供、解約の手続 | アカウントの情報、サポーターの情報 |
| お問い合わせへの回答と、規約や本ポリシーの変更などの重要なお知らせ | アカウントの情報、お問い合わせの情報 |
| 不正なアクセスや規約に違反する行為への対応、障害の調査と再発の防止 | アカウントの情報、投稿と活動、アクセスの情報 |
| 本サービスの改善に使う、個人を特定できない統計の作成 | 投稿と活動、アクセスの情報 |
| 本サービス上での広告の表示 | アクセスの情報 |

広告の表示のために広告配信事業者へ送信される情報は、「7. 外部送信」に書いています。

## 3. 人物情報の取扱い

本サービスは、アニメ作品のキャスト・スタッフとして、作品の制作に関わる方 (以下「人物」) の情報を掲載しています。

- 取り扱う情報: 名前 (読み・英語表記・別名を含む)、性別、誕生日、血液型、身長、出身地、公式サイト・Wikipedia・Xアカウントへのリンク、担当した作品と役職・キャラクター
- 取得元: 作品の公式サイトや公式の発表、ご本人や所属事務所のプロフィールなど、公開されている情報
  - 運営者と、Annict DBの編集者 (本サービスのユーザー) が登録・編集しています
- 利用目的: 作品のキャスト・スタッフの情報として本サービスに掲載し、Web APIで提供するため
  - ユーザーが人物を検索し、お気に入りに登録できるようにするため
- 公開の範囲: 本サービス上で誰でも閲覧でき、Web APIでも提供しています (「4. Web APIによる提供」)

ご本人またはその代理人は、掲載の停止や情報の訂正を申し出ることができます。
「11. お問い合わせ窓口」のメールアドレスまでご連絡ください。
本人確認の方法は「10. 開示等の請求」に書いています。

掲載を停止すると、その人物のページと、作品のキャスト・スタッフ欄のその人物の行を表示しなくなり、Web APIでも提供しなくなります。
同じ人物が再び登録されないよう、掲載を停止した人物の記録は削除せずに残します。
検索エンジンのキャッシュや、Web APIで取得したほかのサービスに残った情報は、運営者が削除できません。

## 4. Web APIによる提供

本サービスは、本サービス上で公開されている情報を、Web API (REST APIとGraphQL API) を通じてほかのアプリケーションやサービスにも提供しています。

- 提供する情報: ユーザーのプロフィール、記録、感想、視聴ステータス、ライブラリ、フォローなど、本サービス上で誰でも閲覧できる情報と、人物の情報
- ユーザーごとにWeb APIでの提供を止める設定はありません
- ユーザーが連携を許可したアプリケーションは、そのユーザーのメールアドレスも取得できます
  - 連携は[連携中のアプリケーションの設定](/settings/apps)からいつでも解除できます

## 5. 第三者への提供

運営者は、次の場合を除き、あらかじめご本人の同意を得ずに個人データを第三者に提供しません。

- 法令に基づく場合
- 人の生命・身体・財産の保護に必要で、ご本人の同意を得ることが難しい場合
- 国の機関などが法令の定める事務を行うことに協力する必要があり、ご本人の同意を得るとその事務に支障を及ぼすおそれがある場合
- そのほか個人情報保護法で認められる場合
- 利用目的の達成に必要な範囲で、個人データの取扱いを委託する場合 (「6. 利用している外部のサービス」)
- 合併などによる事業の承継に伴って提供する場合

## 6. 利用している外部のサービス

運営者は、本サービスの運営に次の外部のサービスを利用し、必要な範囲で個人データの取扱いを委託しています。
保存される国を特定できないものは、その理由と参考になる情報を書いています。

- XServer VPS (サーバー)
  - 用途: 本サービスのサーバーとデータベース
  - 取り扱う情報: 本サービスで取り扱うすべての情報
  - 事業者の所在国: 日本
  - 保存される国: 日本
- Cloudflare (通信の中継・ストレージ)
  - 用途: 通信の中継、Bot対策、画像とデータベースのバックアップの保存
  - 取り扱う情報: 通信の内容、IPアドレス、ユーザーがアップロードした画像、データベースのバックアップ
  - 事業者の所在国: 米国
  - 保存される国: 特定できません
    - Cloudflareが保存先を地域 (アジア太平洋) までしか公表していないためです
- Sentry (エラーの監視)
  - 用途: エラーの検知と調査
  - 取り扱う情報: ユーザーID、ユーザー名、IPアドレス、エラーが起きたページのURL、ブラウザの情報
  - 事業者の所在国: 米国
  - 保存される国: 米国
- Resend (メールの送信)
  - 用途: 確認コード・パスワードの再設定・通知などのメールの送信
  - 取り扱う情報: メールアドレス、メールの件名と本文
  - 事業者の所在国: 米国
  - 保存される国: 日本
- Stripe (決済)
  - 用途: サポーターの決済
  - 取り扱う情報: ユーザーID、Stripeの顧客ID、表示言語
  - 事業者の所在国: 米国 (日本での契約の相手はStripe Japan株式会社)
  - 保存される国: 特定できません
    - Stripeが保存する国を公表していないためです
    - 詳しくは[Stripeのプライバシーポリシー](https://stripe.com/jp/privacy)をご覧ください
- Google Workspace (メールの受信)
  - 用途: お問い合わせのメールの受信と保存
  - 取り扱う情報: お問い合わせのメールアドレスと内容
  - 事業者の所在国: 米国
  - 保存される国: 特定できません
    - Googleが保存する国を公表していないためです
    - 詳しくは[Googleのプライバシーポリシー](https://policies.google.com/privacy?hl=ja)をご覧ください
- Discord (運営者への通知)
  - 用途: フォーラムに新しい投稿があったことを運営者に通知する
  - 取り扱う情報: 投稿者の名前、投稿のタイトルとURL
  - 事業者の所在国: 米国
  - 保存される国: 米国 (ほかの国のサーバーにも保存されることがあります)

外国にある事業者が講じている個人情報の保護のための措置についての情報は、ご請求に応じて提供します。
「11. お問い合わせ窓口」のメールアドレスまでご連絡ください。

## 7. 外部送信

本サービスのページを開くと、ブラウザから次の事業者へ情報が送信されます。

- Google AdSense (Google LLC)
  - 目的: 広告の表示
  - 送信される情報: IPアドレス、ブラウザの情報 (User-Agentなど)、閲覧したページのURL、Googleの広告用のCookie
  - 送信されるページ: 本サービスの多くのページ
  - 運営者はパーソナライズ広告を無効にしています
  - Googleでの情報の利用は[Googleの説明](https://policies.google.com/technologies/ads?hl=ja)をご覧ください
- Google Fonts (Google LLC)
  - 目的: フォントの表示
  - 送信される情報: IPアドレス、ブラウザの情報 (User-Agentなど)、閲覧しているサイトのドメイン
  - 送信されるページ: 本サービスの多くのページ
- Cloudflare Turnstile (Cloudflare, Inc.)
  - 目的: Botによる不正な操作の防止
  - 送信される情報: IPアドレス、ブラウザの情報 (User-Agentなど)、Botを見分けるためのブラウザの動作の情報
  - 送信されるページ: サインイン・新規登録・パスワードの再設定のページ

## 8. ログの取扱い

本サービスは、アクセスのたびに、IPアドレス・閲覧したページ・日時をログに記録します。
メールアドレス・パスワード・トークンなどの値は、伏せてから記録します。
IPアドレスは、不正なアクセスや短い時間に集中したアクセスの調査に使います。
ログは1年間保存したあと削除します。

## 9. 安全管理措置

運営者は、個人データの漏えいなどを防ぐため、次の措置を講じています。

- 組織的な措置
  - 運営者が個人情報の取扱いの責任者を兼ねています
  - Annict DBの編集者の権限は作品データの編集に限り、ユーザーの個人情報を表示する画面はありません
  - 本番環境のデータを扱う作業は、手順と記録を残して行っています
  - [脆弱性の報告窓口](https://github.com/annict/annict/security/policy)を公開しています
- 人的な措置
  - 本番環境 (サーバー・データベース・ストレージ・外部のサービスの管理画面) を操作できるのは運営者だけです
- 物理的な措置
  - 自前の設備を持たず、事業者のサーバーとクラウドサービスを利用しています
  - 運営者の作業用の端末は、ディスクを暗号化し、画面ロックを掛けています
- 技術的な措置
  - 通信をHTTPSで暗号化し、HTTPでの接続はHTTPSに転送しています
    - Cloudflareからサーバーまでの通信も暗号化しています
  - パスワードと確認コードは、ハッシュ化した値だけを保存しています
    - ログイン状態を保つためのIDとパスワードの再設定に使うトークンも、ハッシュ値で保存しています
  - ログイン状態を保つCookieは、HTTPSの通信だけで送られ、JavaScriptから読めないようにしています
  - サインイン・新規登録・パスワードの再設定に、試行の回数の制限とBot対策を設けています
  - データベースへの接続は、運営者のVPNの内側からに限っています
  - データベースのバックアップを毎日取得し、30日分を保存しています
  - ログとエラーの監視では、メールアドレス・パスワード・トークンなどの値を伏せています
  - 利用しているソフトウェアの脆弱性の情報を受け取り、更新しています
  - パスワードなどの秘密の情報は、ソースコードに含めず、パスワード管理サービスで管理しています
  - 開発に使う本番環境のデータベースの複製は、メールアドレス・IPアドレス・パスワードなどを置き換えてから使っています
- 外的環境の把握
  - 外国にある事業者のサービスを利用しています
    事業者の所在国と保存される国は「6. 利用している外部のサービス」のとおりです
  - 米国の個人情報の保護に関する制度は、[個人情報保護委員会の調査](https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/)で把握したうえで、上の措置を講じています

## 10. 開示等の請求

ご本人またはその代理人は、運営者が保有する個人データについて、次のことを請求できます。

- 利用目的の通知
- 開示 (第三者への提供の記録の開示を含みます)
- 内容が事実でない場合の訂正・追加・削除
- 利用の停止・消去
- 第三者への提供の停止

請求は、「11. お問い合わせ窓口」のメールアドレスにお送りください。
書式は定めていません。
請求の種類と対象の情報が分かるようにお書きください。

- 本人確認
  - ユーザーの場合は、運営者から登録されているメールアドレスに確認のメールを送り、その返信で確認します
  - 人物の場合は、ご本人の公式サイトや公式のSNSアカウント、所属事務所など、ご本人が公に使っている連絡の経路で確認します
  - 代理人の場合は、ご本人との関係と委任の事実を確認します
  - 身分証明書の画像などは求めません
- 手数料: 無料です
- 回答の方法: 原則として電子メールで回答します
  - 開示する情報は、電子ファイルでお渡しします

法令により請求に応じる義務がない場合や、本人確認ができない場合は、その旨と理由をお知らせします。

## 12. 退会したときの取扱い

ユーザーは、[アカウントの削除ページ](/settings/account/deletion/new)から退会できます。
退会すると、アカウントの情報、プロフィール、投稿と活動、設定を削除します。
削除は退会の手続のあとに順に行うため、完了まで時間がかかることがあります。

次の情報は、退会後も残ります。

- ほかのユーザーの投稿の中に書かれた、ユーザー名の文字列
- ほかのユーザーのスレッドに書いたフォーラムのコメントの本文 (アカウントとの紐づきは外します)
- Annict DBで編集した作品データの内容と、アップロードした作品画像 (アカウントとの紐づきは外します)
- 新規登録の確認コードの記録 (メールアドレスを含みます)
- Stripeから受け取った決済通知の記録 (顧客IDなどを含むことがあります)

確認コードと決済通知の記録には、保存期限を設けていません。

次の情報は、退会後も一定の期間残り、期間が過ぎると削除されます。

- データベースのバックアップ: 30日
- ログ: 1年
- エラーの監視 (Sentry) の記録: 30日
- メールの送信 (Resend) の記録: 30日
- ほかの端末のログイン状態の記録: 最後にアクセスしてから30日
- 開発用の環境に複製したプロフィール画像: 次に複製し直すまで

Stripeで申し込んだサポーターが退会すると、サブスクリプションをその時点で解約します。
Stripe上の決済の記録は、Stripeの定めに従って保存されます。

Gumroadで申し込んだサポーターのサブスクリプションは、退会しても解約されません。
Gumroadで解約してください。

## 13. 本ポリシーの変更

運営者は、法令の改正や本サービスの変更に合わせて、本ポリシーを変更することがあります。
変更するときは、本サービス上またはヘルプでお知らせし、あわせて本サービスの公式SNSアカウントでもお知らせします。
法令上ご本人の同意が必要な変更をするときは、同意を得ます。
