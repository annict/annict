## 本規約の新設について

本規約を2026年10月15日に定め、2026年11月15日から施行します。
これまでAPIを利用していた方の多くは、使い方を変えずに引き続き利用できます。
施行日までに、使い方が本規約に沿っているかをご確認ください。
本規約に同意いただけない場合は、施行日までにAPIの利用をやめ、登録したアプリケーションとアクセストークンを削除してください。

本規約で定めた点は次のとおりです。

- APIの利用に料金がかからず、商用でも個別の許可なく利用できることを定めました
- 利用者情報を、アプリケーションの中で表示することと、Annictの外に転載することを分けて定めました
- 取得したデータの保存とキャッシュの条件と、再配布の禁止を定めました
- Annictのアカウントを求めないアプリケーションで、1つのアクセストークンを共用する場合の条件を定めました
- APIで提供していない作品情報を、Webサイトから機械的に取得する場合の条件を定めました
- AI・機械学習での利用と、画像の取扱いの条件を定めました
- レート制限、OAuthアプリケーションの譲渡、Annictの名称とロゴの表示について定めました
- APIの提供を終了するときは、1年前までにお知らせすることを定めました

本規約の施行前に運営者が個別に利用を認めた目的は、施行後も引き続き認めます (「附則」)。
本規約は新しく定めたもので、改定前の版はありません。

アニメ視聴記録サービス「Annict」(以下「本サービス」) の運営者 (以下「運営者」) は、本サービスのAPIを利用するときの条件を、次のとおりAPI利用規約 (以下「本規約」) として定めます。
本規約は、[利用規約](/terms)に加えて適用されます。

## 第1条 (適用範囲)

本規約は、次のもの (以下まとめて「API」) を利用するすべての方 (以下「開発者」) に適用されます。

- REST API V1
- GraphQL API
- OAuthによるアプリケーションの連携
- 個人用アクセストークン
- 今後提供するAPI (REST API V2を含みます)

本サービスのWebサイトから情報を機械的に取得する場合も、本規約を適用します (「第8条 (Webサイトからの機械的な取得)」)。

本規約に定めの無いことは、利用規約に従います。
APIの利用について本規約と利用規約の定めが異なるときは、本規約の定めを優先します。

## 第2条 (定義)

本規約で使う言葉の意味は、次のとおりです。

- 作品情報: 作品・エピソード・放送予定・キャラクター・人物・団体・キャスト・スタッフ・シリーズなど、本サービスのユーザー以外についての情報
- 利用者情報: プロフィール・記録・感想・視聴ステータス・ライブラリ・フォローなど、本サービスのユーザーについての情報
- アプリケーション: 開発者がAPIを利用して作るアプリ・Webサイト・サービス・プログラム

## 第3条 (料金と商用利用)

APIの利用に料金はかかりません。
有償の利用契約も設けていません。

開発者は、本規約を守る限り、商用か非商用かを問わず、個別の許可なくAPIを利用できます。
広告やアフィリエイトで収益を得るアプリケーションや、有料の機能を持つアプリケーションでの利用も含みます。

運営者の個別の許可が必要なのは、次の場合だけです。

- AI・機械学習に商用の目的で利用する場合 (「第9条 (AI・機械学習での利用)」)
- 取得したデータをデータセットとして第三者に提供する場合 (「第6条 (取得したデータの取扱い)」)

## 第4条 (認証)

運営者は、OAuthでアプリケーションを連携する方法をおすすめします。
OAuthでは、アプリケーションが必要な権限 (スコープ) だけを求められ、ユーザーはアプリケーションごとに連携を解除できるためです。

個人用アクセストークンを使う場合は、次のことを守ってください。

- アクセストークンを、第三者に知られないように保管すること
- ユーザーに個人用アクセストークンを入力させるアプリケーションでは、そのトークンでできることと、トークンを他人に教えないことをユーザーに説明すること
- 自分のアクセストークンを第三者に渡さないこと
  ただし、「第5条 (配布物に埋め込む共用トークン)」の場合を除きます

## 第5条 (配布物に埋め込む共用トークン)

Annictのアカウントの作成をユーザーに求めないアプリケーションでは、開発者自身の個人用アクセストークンを1つだけアプリケーションに埋め込み、すべてのユーザーのリクエストに使うことができます。
その場合は、次の条件をすべて守ってください。

- そのトークンで取得するのは作品情報だけにし、利用者情報を取得しないこと
- 読み取り (`read`) のスコープだけで発行したトークンを使うこと
- 運営者がそのトークンを失効させることがあると了解し、トークンを差し替えられる作りにしておくこと

アプリケーションに埋め込んだトークンは、第三者に取り出されることがあります。
取り出されたトークンが悪用されたときは、運営者は開発者に前もって連絡せずに、そのトークンを失効させることがあります。

## 第6条 (取得したデータの取扱い)

開発者は、APIで取得したデータを、そのままの形で、またはまとまったデータとして第三者が取り出せるように提供してはいけません。
ファイルでの配布、データセットとしての公開、自分のAPIでの再提供などがこれに当たります。
運営者が個別に許可した場合は除きます。
作品情報をアプリケーションの画面やページに表示することは、これに当たりません。

利用者情報は、アプリケーションの中で表示することと、Annictの外に転載することを分けて扱います。

- 表示: アプリケーションのユーザーに、Annictの機能として利用者情報を見せることです
  クライアントアプリでユーザー名や感想を見せることなどが当たります
  次の条件をすべて守る限り、表示できます
  - APIから取得した内容を変えずに見せること
  - 本サービス上で公開されている範囲を超えて見せないこと
  - 本サービス上で削除・非公開にされた情報は見せないようにすること
  - 表示のために必要な範囲を超えて、複製をためないこと
- 転載: 利用者情報をAnnictの外の公開物に載せることです
  Webサイトへの掲載、論文での引用、データセットへの収録、SNSへの投稿などが当たります
  その利用者情報のユーザー本人が同意した場合を除き、転載してはいけません

個人を特定できない統計や集計の結果は、転載に当たりません。
自由に公開できます。

## 第7条 (データの保存とキャッシュ)

開発者は、アプリケーションの提供に必要な範囲で、APIで取得したデータを保存・キャッシュできます。
保存する場所が開発者のサーバーか、ユーザーの端末の中かは問いません。

作品情報は、次のとおり扱えます。

- 保存する期間と件数に上限はありません
  全件を保存することもできます
- APIの利用をやめた後も、消去する必要はありません
- 作品などのIDを、アプリケーションの中で作品を見分けたり紐付けたりするために保持できます

作品情報は、本サービス上で訂正・統合・削除・非公開にされることがあります。
定期的に取得し直し、アプリケーションに反映していただけると助かります。
掲載を停止した人物は、取得し直すとAPIで見つからなくなります。
その場合は、アプリケーションからもその人物の情報を外してください。
取得し直す頻度の目安は、[開発者向けヘルプ](https://wikino.app/s/annict/pages/357)の「Annictのレート制限」に載せています。

利用者情報は、次のときに削除してください。
バックアップに残ったものは、通常の保持期間が過ぎたら消去してください。

- ユーザーがアプリケーションとの連携を解除したとき: そのユーザーの利用者情報
- APIの利用をやめたとき: すべての利用者情報

## 第8条 (Webサイトからの機械的な取得)

APIで提供している情報は、APIで取得してください。

APIで提供していない作品情報 (配信サービスへのリンクなど) は、次のことを守る限り、個別の許可なく本サービスのWebサイトから機械的に取得できます。

- robots.txtに従うこと
- 「第11条 (レート制限)」のレート制限の範囲で取得すること

利用者情報は、Webサイトから機械的に取得してはいけません。
利用規約で禁止しているためです。

WebサイトのHTMLの構造は、予告なく変わることがあります。
運営者は、Webサイトからの機械的な取得が動き続けることを保証せず、そのためのサポートもしません。
運営者から取得をやめるよう求められたときは、やめてください。

機械的に取得するときは、`User-Agent` ヘッダーにアプリケーションの名前と連絡先 (WebサイトのURLやメールアドレス) を入れていただけると助かります。
負荷が高くなったときに、アクセスを遮断する前にご連絡できることがあります。

## 第9条 (AI・機械学習での利用)

APIで取得したデータを、AI・機械学習に利用できます。
ただし、目的によって次の条件があります。

- 研究や非商用の目的: 次の条件を守る限り、個別の許可なく利用できます
  - 取得したデータを再配布しないこと (「第6条 (取得したデータの取扱い)」)
  - 論文やモデルの出力例などの成果物に、個人を特定できる形で利用者情報を載せないこと
- 商用の目的: 運営者の個別の許可が必要です

どちらの目的でも、データはAPIで取得してください。
運営者は、データベースの複製 (データダンプ) は提供しません。

## 第10条 (画像の取扱い)

APIが提供する作品の画像と、Webサイトに表示している画像の著作権は、それぞれの権利者にあります。
APIが提供する作品の画像には、作品の公式サイトの画像や公式SNSアカウントのプロフィール画像などのURLがあります。
運営者は、これらの画像の利用を許諾できる立場にありません。

画像は、ご自身の責任で、法令で認められる範囲 (作品を紹介するリンクに添える表示など) で利用してください。
次のことはしてはいけません。

- 画像を再配布すること
- 画像を改変すること
- 画像をデータセットとして提供すること

画像のURLには、リンクが切れているものも含まれます。
運営者は、権利者からの申出などにより、予告なく画像の提供をやめたり変えたりすることがあります。

「第8条 (Webサイトからの機械的な取得)」でWebサイトからの取得を認めていても、Webサイトの画像を利用することまでは許諾していません。
Webサイトから取得した画像にも、本条の条件が適用されます。

## 第11条 (レート制限)

APIとWebサイトへのリクエストには、運営者が別に定めるレート制限が適用されます。
レート制限の内容は、[開発者向けヘルプ](https://wikino.app/s/annict/pages/357)の「Annictのレート制限」に載せています。

レート制限は見直すことがあります。
常に最新のレート制限が適用されます。

## 第12条 (OAuthアプリケーションの譲渡)

開発者は、登録したOAuthアプリケーションを第三者に譲渡できません。
アプリケーションを別の人や法人に引き継ぐときは、引き継ぐ人の名義でアプリケーションを新しく登録し、ユーザーにあらためて連携を許可してもらってください。

ユーザーが知らないうちに、記録の読み書きを別の相手に許可した状態になることを防ぐためです。

## 第13条 (名称・ロゴの表示)

アプリケーションでAnnictをデータの出典として示すかどうかは自由です。
示していただけるとうれしいです。
示す場合の書き方も問いません。

Annictの名称とロゴは、データの出典を示すためや、アプリケーションの機能を説明するため (「Annictの記録を付けるアプリ」など) に使えます。

一方で、アプリケーションがAnnictの公式のものや提携先のものであるとユーザーが誤解するような表示をしてはいけません。
アプリケーションの名前・アイコン・ストアの説明文などに、Annictの名称やロゴを冠することがこれに当たります。

## 第14条 (保証しないことと仕様の変更)

運営者は、次のことを開発者にお知らせします。

- APIの仕様と、WebサイトのHTMLの構造は、予告なく変わることがあります
- APIの提供を終えることがあります
  APIのあるバージョンやAPI全体の提供を終えるときは、終える日の1年前までに開発者向けヘルプなどでお知らせします
- 作品などのIDは、作品の統合・削除や、APIのバージョンの移行によって、変わったり参照できなくなったりすることがあります
- 運営者は、APIで提供する情報が正確であることや、APIをいつでも利用できることを保証しません
- 運営者は、アプリケーションやWebサイトからの機械的な取得についてのサポートはしません
  アプリケーションとそのユーザーとの間で起きたトラブルには、開発者が対応してください

運営者が負う責任の範囲は、利用規約の定めに従います。

## 第15条 (違反したときの措置)

開発者が本規約や利用規約に違反したときや、本サービスの運営に支障が出る使い方をしたときは、運営者は前もって通知せずに次の措置を取ることがあります。

- アクセストークンを失効させる
- OAuthアプリケーションの登録を削除する
- APIやWebサイトへのアクセスを遮断する

## 第16条 (本規約の変更)

運営者は、利用規約を変更するときと同じ手続で、本規約を変更することがあります。
APIに新しい条件が必要になったとき (REST API V2に固有の条件など) にも、本規約を変更します。
